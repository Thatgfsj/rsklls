# rust-skills

Rust 程序开发专家技能，用于 Claude Code 等 AI Agent。

## 描述

涵盖 Rust 核心开发及跨语言互操作：

- **Rust 核心开发**: 所有权、借用、生命周期、trait、异步编程
- **Python-Rust 互操作**: PyO3, maturin
- **Go-Rust 互操作**: cgo, cxx, C FFI
- **Java-Rust 互操作**: JNI
- **C/C++-Rust 互操作**: FFI, cxx

## 触发词

`rust`, `cargo`, `pyo3`, `maturin`, `rust python`, `rust go`, `cgo`, `jni`, `rust ffi`, `tokio`

## 使用方法

将此 skill 放置在 AI 的 skills 目录中，当用户请求涉及 Rust 开发或跨语言互操作时自动触发。
